レシピの取り込み

受け付けるJSONの形

  • レシピの配列([...])で書く
  • title: 名前(必須)
  • body: 本文(省略すると空)
  • tags: タグ名の配列(省略すると無し)
  • cooked_count: 作った回数(0以上の整数、省略すると0)
  • 画像は取り込めない(取り込んだあと詳細ページで付ける)
  • 同じ名前のレシピがあっても別のレシピとして登録される
  • 1件でも不正があれば1件も登録しない
  • 一度に送れるのは5MBまで
[
  {
    "title": "肉じゃが",
    "body": "じゃがいも 3個\n玉ねぎ 1個\n牛肉 200g\n\n1. 材料を切る\n2. 炒めてから煮る",
    "tags": ["和食", "煮物"],
    "cooked_count": 2
  },
  {
    "title": "味噌汁"
  }
]
